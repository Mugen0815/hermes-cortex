# 60 Maps — Map of Content

This folder holds index/overview notes (MOCs) that group related notes for
navigation. The README itself is a valid public note so seed installation and
indexing do not trip over a raw, frontmatter-less stub.

Examples:
- `Map - Jarvis Knowledge Index.md` — top-level entry into vault
- `Map - Infrastructure.md` — VMs, hosts, networking, services
