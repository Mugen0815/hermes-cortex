# long-term-memory

Skills for structured long-term memory using a cortex-indexed Obsidian vault.

## Skill selection

| When you want to... | Load... |
|---|---|
| Retrieve knowledge from memory / vault / sessions | `memory-query-flow` |
| Debug memory hooks, ranking, SessionDB/search latency, or Cortex CLI issues | `memory-diagnostics` |
| Write, edit, or name a note | `obsidian` |
| Set up or repair vault structure, templates, or bootstrap | `vault-infrastructure` |

## Boundaries

- **`memory` tool** → compact single facts ("Remember...", user corrections)
- **Vault** → structured durable knowledge (projects, runbooks, decisions, facts)
- **Skills** → procedural knowledge (setups, bug fixes, recurring workflows)
